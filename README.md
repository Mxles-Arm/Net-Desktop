# CAI Net — Net Desktop

บทเรียนคอมพิวเตอร์ช่วยสอน (CAI) จำลองเครือข่าย LAN และ Wi-Fi ภายในห้องเรียน หน้าตาแบบ Mac OS X
ผู้เรียนลากอุปกรณ์มาต่อสาย ตั้งค่า IP แล้วทดสอบด้วย Ping / Traceroute / Terminal ได้เหมือนของจริง
มีภารกิจ แบบทดสอบก่อน–หลังเรียน แบบประเมินความพึงพอใจ และหน้าสรุปผลสำหรับครู (E1/E2)

## วิธีรัน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป (ไม่มีค่าใช้จ่ายใด ๆ)

```bash
npm run setup     # ติดตั้งครั้งแรกครั้งเดียว (ต้องต่ออินเทอร์เน็ต)
npm start         # เปิดเซิร์ฟเวอร์
```

จากนั้นเปิด <http://localhost:3000>

- **ผู้เรียน**: เข้าสู่ระบบด้วยรหัสนักเรียน + ชื่อ (ไม่ต้องมีรหัสผ่าน)
- **ครู**: <http://localhost:3000/teacher.html> รหัสผ่านเริ่มต้น `teacher1234`
  เปลี่ยนได้โดยตั้งตัวแปร `TEACHER_PASSWORD` ก่อนรัน เช่น `set TEACHER_PASSWORD=รหัสใหม่` (Windows) แล้ว `npm start`
- **ให้เพื่อนในห้องเข้าใช้**: ต่อ Wi-Fi วงเดียวกัน แล้วเข้าที่ IP ที่เซิร์ฟเวอร์พิมพ์ไว้ตอนเปิด เช่น `http://192.168.1.35:3000`
- ทดสอบระบบหลังบ้าน: `npm test`
- เบราว์เซอร์หนึ่งตัวล็อกอินได้ทีละบัญชี ถ้าจะเปิดหน้าครูกับหน้าผู้เรียนพร้อมกัน ให้ใช้หน้าต่างไม่ระบุตัวตน (Incognito) แยกกัน

ข้อมูลทั้งหมดเก็บในไฟล์ `backend/data/cai-net.db` (SQLite) ถ้าจะเริ่มเก็บข้อมูลใหม่ (เช่น ก่อนทดลองกับกลุ่มตัวอย่างจริง) ให้ปิดเซิร์ฟเวอร์แล้วลบโฟลเดอร์ `backend/data`

## โครงสร้างโปรเจกต์

```
frontend/            หน้าบ้าน (HTML/CSS/JS ล้วน ไม่ต้อง build)
  index.html         หน้าหลักของผู้เรียน
  teacher.html       หน้าสรุปผลของครู
  css/style.css      หน้าตาเดิมของ Net Desktop
  css/cai.css        หน้าตาของส่วนที่เพิ่ม (ล็อกอิน ภารกิจ แบบทดสอบ Terminal ฯลฯ)
  js/app.js          Desktop, Workspace, การลากอุปกรณ์ (โค้ดเดิม + จุดเชื่อมต่อ)
  js/api.js          ฟังก์ชันเรียก API ของหลังบ้าน
  js/cai.js          ฟีเจอร์ที่ต่อกับหลังบ้าน (ล็อกอิน บันทึก ภารกิจ คำใบ้ Network Utility Terminal)
  js/teacher.js      หน้าครู
  assets/            รูปภาพ
backend/             หลังบ้าน (Node.js + Express + SQLite)
  src/server.js      จุดเริ่มเซิร์ฟเวอร์
  src/app.js         API ทั้งหมด
  src/engine/        Network Engine — จำลอง IP, Subnet, Gateway, DHCP, DNS, Wi-Fi, ping, traceroute, คำสั่ง Terminal
  src/content/       เนื้อหา: บทเรียน ภารกิจ แบบทดสอบ แบบประเมิน (แก้ไขเนื้อหา/ข้อสอบ/ภารกิจได้ที่นี่)
  src/stats.js       คำนวณคะแนน E1/E2 ความพึงพอใจ และไฟล์ CSV
  test/              ชุดทดสอบอัตโนมัติ
docs/
  API.md             รายการ API ทั้งหมด
  DATA-FORMAT.md     รูปแบบข้อมูล Workspace (อุปกรณ์ สาย ค่าเครือข่าย)
```

## สำหรับคนแต่งหน้าบ้าน

- แก้หน้าตาได้ที่ `css/style.css` และ `css/cai.css` ได้เลย ไม่กระทบหลังบ้าน
- อย่าเปลี่ยนชื่อ `class` / `id` / `data-*` ที่ JavaScript ใช้อ้างอิง เช่น `data-field`, `data-cmd`, `data-dock`, `.mission-check`, `[data-net-status]`, `[data-device-status]`, `.mission-panel`
- ถ้าเพิ่มค่าใหม่ให้อุปกรณ์ ดูชื่อฟิลด์ที่หลังบ้านอ่านใน `docs/DATA-FORMAT.md`
- ฟังก์ชันใน `app.js` เรียกฟีเจอร์ใหม่ผ่าน `window.CAI` (มีหลังจากผู้เรียนล็อกอินแล้ว)

## สิ่งที่ระบบทำได้

| ส่วน | ทำอะไรได้ |
|---|---|
| ล็อกอิน | ผู้เรียนเข้าด้วยรหัสนักเรียน ครูเข้าด้วยรหัสผ่าน |
| Finder (Dock) / File → Save | บันทึก เปิด ลบงานบนเซิร์ฟเวอร์ บันทึกอัตโนมัติทุก 20 วินาทีหลังบันทึกครั้งแรก |
| Inspector | ตั้งค่า IP / Subnet Mask / Gateway / DNS / DHCP และแสดงปัญหาของอุปกรณ์ที่เลือก |
| ตรวจสด | ตรวจเครือข่ายทุกครั้งที่แก้ไข อุปกรณ์ที่มีปัญหามีกรอบแดง/เหลือง |
| ทดสอบเครือข่าย | รายการปัญหาทั้งหมด เช่น IP ซ้ำ, Gateway คนละวง, รหัส Wi-Fi ผิด |
| ส่ง Packet | วิ่งตามเส้นทางจริงผ่าน Switch/Router ถ้าไปไม่ถึงจะบอกสาเหตุ |
| Network Utility (Dock) | ข้อมูลเครือข่าย, Ping, Traceroute, DNS Lookup |
| Terminal (Dock) | `ipconfig`, `ping`, `tracert`, `arp -a`, `nslookup`, `hostname`, `help` |
| Mission Control (Dock) | บทเรียน 4 บท คู่กับ 4 ภารกิจ ภารกิจปลดล็อกตามลำดับ ตรวจผ่านอัตโนมัติ ให้คะแนนและเหรียญ + คำถามหลังภารกิจ |
| CAI Assistant (มาสคอต) | คำใบ้ 3 ระดับตามปัญหาจริง (บอกปัญหา → ชี้อุปกรณ์ → บอกวิธีแก้) |
| Learn (เมนู) | แบบทดสอบก่อน/หลังเรียน 10 ข้อ พร้อมเฉลยและคำอธิบาย, แบบประเมินความพึงพอใจ 8 ข้อ |
| หน้าครู | คะแนนรายคน, จำนวนบทเรียนที่อ่าน, E1/E2, x̄ และ S.D. ความพึงพอใจ, จุดที่ผิดบ่อย, Export CSV เปิดใน Excel ได้ |
