# วิธีเอา CAI Net ขึ้น Host (Render + Turso) — ฟรี

ระบบนี้ใช้ 2 บริการ:

- **Render** — รันเว็บและหลังบ้าน (Node.js) ได้ลิงก์ `https://….onrender.com`
- **Turso** — เก็บฐานข้อมูล (คะแนน งาน บัญชีผู้เรียน) เพราะ Render แบบฟรีจะลบไฟล์ในเครื่องทุกครั้งที่รีสตาร์ต

> ⚠️ **รหัสเชื่อมต่อ (Auth Token) ของ Turso เป็นความลับ** ใส่ในหน้าตั้งค่าของ Render เท่านั้น
> ห้ามใส่ในโค้ด ห้ามส่งในแชต เพราะ repo นี้เป็นสาธารณะ

---

## ส่วนที่ 1: สร้างฐานข้อมูลบน Turso

1. เข้า <https://turso.tech> แล้วสมัคร (Sign up) — ล็อกอินด้วย GitHub ได้
2. สร้างฐานข้อมูลใหม่ ตั้งชื่อเช่น `cai-net`
   - **ถ้ามีให้เลือกชนิดฐานข้อมูล ให้เลือก `libSQL`** (ไม่ใช่ Turso Database แบบใหม่)
     เพราะระบบใช้ไลบรารี `@libsql/client` ซึ่งใช้กับฐานข้อมูลแบบ libSQL
   - ถ้ามีให้เลือกตำแหน่ง (location) เลือกที่ใกล้ที่สุด
3. คัดลอกค่า 2 อย่างเก็บไว้:
   - **Database URL** — ขึ้นต้นด้วย `libsql://`
   - **Auth Token** — กดสร้าง Token (สิทธิ์อ่าน-เขียน) แล้วคัดลอก (บางครั้งแสดงครั้งเดียว)

> ชื่อปุ่มบนเว็บ Turso อาจต่างจากนี้เล็กน้อย ถ้าใช้คำสั่งแทน (ต้องมี WSL บน Windows):
> `turso db create cai-net` → `turso db show cai-net --url` → `turso db tokens create cai-net`

ไม่ต้องสร้างตารางเอง — เซิร์ฟเวอร์สร้างให้อัตโนมัติตอนเปิดครั้งแรก

## ส่วนที่ 2: สร้างเว็บบน Render

1. เข้า <https://render.com> แล้วสมัคร — ล็อกอินด้วย GitHub ที่มี repo `Mxles-Arm/Net-Desktop`
2. กด **New** → **Blueprint** แล้วเลือก repo `Net-Desktop`
   Render จะอ่านไฟล์ `render.yaml` และสร้างเว็บชื่อ `cai-net` แบบ **Free** ให้
3. Render จะถามค่า 3 ช่อง (ถามครั้งเดียวตอนสร้าง):

   | ช่อง | ใส่อะไร |
   |---|---|
   | `TURSO_DATABASE_URL` | Database URL จาก Turso (`libsql://…`) |
   | `TURSO_AUTH_TOKEN` | Auth Token จาก Turso |
   | `TEACHER_PASSWORD` | รหัสผ่านครูที่ตั้งใหม่ (อย่าใช้ `teacher1234`) |

4. กดสร้าง แล้วรอ Build เสร็จ (ดูใน Logs) จะเห็นบรรทัด
   `ฐานข้อมูล: Turso (libsql://…)` แปลว่าต่อฐานข้อมูลสำเร็จ
5. เปิดลิงก์ `https://cai-net….onrender.com` ที่ Render ให้มา

ถ้าลืมใส่ค่าหรือใส่ผิด: เข้าเว็บ `cai-net` บน Render → **Environment** → แก้ค่า → บันทึก (Render จะ deploy ใหม่ให้)

## ส่วนที่ 3: ตรวจก่อนวันพรีเซนต์

- [ ] ล็อกอินเป็นนักเรียนได้ ทำภารกิจ 1 ผ่าน
- [ ] เข้า `/teacher.html` ด้วยรหัสผ่านครูใหม่ได้ เห็นคะแนน
- [ ] **ทดสอบว่าข้อมูลไม่หาย:** สั่ง Restart เว็บในหน้า `cai-net` บน Render (หรือรอให้เว็บหลับเกิน 15 นาที) แล้วล็อกอินใหม่ — คะแนนเดิมต้องยังอยู่
- [ ] ลบบัญชีทดสอบในหน้าครูก่อนให้กลุ่มตัวอย่างใช้จริง

## เรื่องที่ควรรู้ (แพ็กเกจฟรีของ Render)

- เว็บจะ **หลับถ้าไม่มีคนเข้า 15 นาที** และตื่นเมื่อมีคนเปิด ใช้เวลา **ประมาณ 1 นาที**
  → เช้าวันพรีเซนต์ให้เปิดเว็บทิ้งไว้ก่อนเริ่มสักพัก (ข้อมูลไม่หาย เพราะอยู่บน Turso)
- ใช้ได้ 750 ชั่วโมงต่อเดือน (เปิดเว็บเดียวทั้งเดือนไม่หมด)
- Region เริ่มต้นคือ Oregon (สหรัฐฯ) ใช้งานได้ปกติ แต่ช้ากว่าเซิร์ฟเวอร์ในเอเชียเล็กน้อย
- ทุกครั้งที่ push ขึ้น GitHub สาขา `main` Render จะ deploy ใหม่ให้อัตโนมัติ

## ถ้ามีปัญหา

| อาการ | สาเหตุที่น่าจะเป็น |
|---|---|
| Logs ขึ้น `เปิดเซิร์ฟเวอร์ไม่สำเร็จ` + `ตรวจค่า TURSO_DATABASE_URL…` | URL หรือ Token ผิด / Token หมดอายุ / เลือกฐานข้อมูลผิดชนิด (ต้องเป็น libSQL) |
| เปิดเว็บแล้วหมุนนาน | เว็บกำลังตื่นจากการหลับ รอประมาณ 1 นาที |
| หน้าเว็บขึ้น "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้" | เปิดผิดลิงก์ (เช่น ลิงก์ static hosting เดิม) ต้องใช้ลิงก์ของ Render |

## รันบนเครื่องตัวเองยังได้เหมือนเดิม

ถ้าไม่ได้ตั้ง `TURSO_DATABASE_URL` ระบบจะเก็บข้อมูลในไฟล์ `backend/data/cai-net.db` บนเครื่องตามเดิม (`npm start`)
